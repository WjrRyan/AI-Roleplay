# AI 绩效陪练 (AI Coach)

## 功能描述
AI 绩效陪练是一个基于大语言模型的模拟演练工具，旨在帮助管理者提升与 C 类绩效员工进行面谈的能力。

主要功能包括：
1.  **AI 助手入口**：通过浮动助手入口进入陪练模式。
2.  **任务简报 (Intro)**：介绍本次演练的背景、目标和通关条件。
3.  **角色设定 (Setup)**：选择或自定义陪练对象的性格、职位和绩效问题。
4.  **实战演练 (Chat)**：与 AI 扮演的员工进行实时对话，支持语音输入和 AI 语音回复。提供实时话术分析和建议。
5.  **深度报告 (Report)**：基于 SBI、GROW 等模型生成多维度的评估报告，指出优势与不足。
6.  **历史记录 (History)**：查看和回顾过往的演练记录。

## 适配终端
- **响应式 (PC + 移动端)**
- PC 端：提供完整的大屏体验，侧边栏显示角色档案。
- 移动端：适配小屏操作，角色档案通过抽屉 (Drawer) 展示。

## 目录结构
- `components/`: 页面独有的 UI 组件
- `utils/`: 工具函数和 API 服务
- `types.ts`: 类型定义
- `constants.ts`: 常量定义
- `index.tsx`: 页面入口组件
